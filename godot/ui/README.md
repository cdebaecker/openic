Interface art drawn for OpenIC (not from the game): the OpenIllusionCity logo and the window frame
of the project's website (Helly Studios), drawn by its tools/logos.py in the colours of the X68000
game.

They are PNG files named .rawpng so that Godot exports them as they are instead of importing
them (the release's export template can't decode imported, WebP-compressed textures); the title
menu decodes them itself.
