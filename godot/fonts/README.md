# Fonts

`unifont_jp-15.1.05.otf` — GNU Unifont 15.1.05, Japanese variant (16-dot bitmap glyphs: 16×16
kanji/kana, 8×16 Latin), from https://ftp.gnu.org/gnu/unifont/unifont-15.1.05/. It stands in for
the X68000's 16-dot font ROM, which is not ours to ship. Licensed under the SIL Open Font License
1.1 (`OFL-1.1.txt`; Unifont is dual-licensed GPL 2+ with the font embedding exception or OFL 1.1).
Loaded at run time without antialiasing or hinting (`GameText.font`) so glyphs stay on the 16-dot
grid.
